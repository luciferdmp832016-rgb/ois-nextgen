# OIS Architecture Mindmap Agent Foundation

Stage 2G adds a machine-readable OIS ecosystem map for future architecture agents.

Canonical source file:

- `architecture/mindmap/ois-ecosystem-map.v1.json`

Core API route:

- `GET /platform/architecture/mindmap`

The manifest includes:

- OIS core layers
- Powered by OIS product keys
- KL-0 through KL-5 knowledge layers
- Stage 2F learning flow
- Stage 2G knowledge fabric flow
- API contracts
- governance checkpoints

This is not an autonomous architecture agent yet. It is a deterministic manifest for future navigation, explanation and provenance-aware tooling.
