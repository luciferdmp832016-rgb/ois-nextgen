# OIS Ecosystem Platform

Stage 2F unifies the OIS Core Platform and OIS-powered ecosystem products around a shared learning and agent runtime foundation.

## Core Principle

OIS Core is the shared brain.

Ecosystem products are consumers and contributors. They can query, display evidence and submit learning feedback, but they do not own canonical intelligence independently.

## Platform Layers

| Layer | Stage 2F role |
|---|---|
| Knowledge Layer | Master Knowledge, Entity Registry, KnowledgeEntityLink, Decisions, Commitments, Risks and Evidence Graph remain canonical and protected. |
| Executive Intent Layer | CEO/BOD/C-level statements can enter as high-authority learning signals and executive intent candidates. |
| Self-Improvement Engine | Learning Signals become Learning Candidates with confidence scoring, source authority scoring, conflict checks and promotion placeholders. |
| Learning Governance | Policy modes decide review, auto-log or log-only behavior with audit. |
| Universal Knowledge API | Query, evidence, context, entity and learning feedback contracts are declared for later cross-product reuse. |
| OIS Agent Runtime | Shared widget shell, product context adapter, chat stub, learning intake endpoint and evidence-aware response contract. |

## Canonical Boundary

Allowed Stage 2F flow:

`User/product input -> OIS Agent Widget -> Learning Signal -> Learning Candidate -> Confidence/Policy/Review/Audit -> future Knowledge Promotion`

Forbidden Stage 2F flow:

`User/product input -> Widget -> direct Master Knowledge / Entity Registry / Decision / Commitment / Risk write`

AUTO_LEARN in Stage 2F means candidate status/log only. It does not promote content into the Knowledge Layer.
